# Backend Development

**Holberton School · Software Engineering Coursework**

Backend engineering exercises spanning modern JavaScript, Node.js HTTP services, asynchronous Python, NoSQL queries, and API pagination.

## Technology and concepts

JavaScript (ES6), Node.js, Python, MongoDB, API design and pagination.

## Modules

| Directory | Focus |
| --- | --- |
| [`ES6_basic/`](./ES6_basic/) | Modern JavaScript syntax: constants, block scope, arrow functions, rest/spread, template literals and object notation. |
| [`ES6_classes/`](./ES6_classes/) | Object-oriented JavaScript with ES6 classes, constructors, inheritance and related language features. |
| [`ES6_data_manipulation/`](./ES6_data_manipulation/) | Arrays, maps, sets, typed arrays and collection transformations. |
| [`ES6_promise/`](./ES6_promise/) | Promise creation, chaining, asynchronous coordination and error handling. |
| [`Node_JS_basic/`](./Node_JS_basic/) | Node.js console applications, file I/O and HTTP servers with Express. |
| [`NoSQL/`](./NoSQL/) | MongoDB commands and Python-based data retrieval, inserts and updates. |
| [`pagination/`](./pagination/) | Pagination helpers, page metadata, hypermedia and deletion-resilient pagination. |
| [`python_async_comprehension/`](./python_async_comprehension/) | Asynchronous generators, comprehensions and runtime analysis. |
| [`python_async_function/`](./python_async_function/) | Async/await, concurrent coroutines and task scheduling. |
| [`python_variable_annotations/`](./python_variable_annotations/) | Python type annotations for variables, functions and collections. |

## Working with the exercises

Review the individual directory README files and exercise source before running or compiling them. Each task may have its own dependencies, test driver, or required inputs; do not assume every file is a standalone program.
